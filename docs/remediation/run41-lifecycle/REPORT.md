**Implemented behavior**

Capture attempts now record their exact snapshot membership in the existing evaluation audit, using the `setup-capture-membership-v1` contract. Each member pins the snapshot's original creator, immutable SETUP evidence address and payload fingerprint, source-data hash, and frozen market context. A fingerprint covers the complete membership and capture scope.

The evaluator verifies this retained membership instead of treating the latest capture attempt as the creator of reused snapshots. Mixed creators are supported. Legacy captures without membership retain the original strict creator check; this includes run 41's capture 58. Snapshot creators and financial evidence are never rewritten to make validation pass.

Membership is an operational provenance record, not financial authority. Native source, configuration, projection and decision validation remain mandatory. Canonical selections, changes, episodes, transitions, alerts and successful evaluation still publish in the existing atomic lifecycle transaction. Recapture failures and cancellation roll back staged business work before a separately fenced failure/cancellation audit is written.

Internal recapture now forwards bounded progress and cancellation checkpoints through source preparation, reconstruction and evidence persistence. Pipeline logs record the resolved handoff switch and selected input path; capture logs distinguish new artifacts from reused artifacts. `SetupCaptureHandoffError` supplies a stable deterministic error code and bounded provenance diagnostics, including capture attempt, pipeline/run, offending snapshot and expected/actual ownership where available.

Exception logs retain bounded traceback locations and exception chains, including SQLSTATE when present, without source lines or frame locals. The E2E environment's database URL is excluded from its representation so fixture failures cannot display connection credentials.

No schema migration, timeout increase, formula change, global relaxation of ownership validation, or edit to run 41's immutable false configuration anchor is required.
