# Glossary

| Term | Meaning |
| --- | --- |
| Advisory overlay | Context that can guide interpretation but must not place orders or silently rewrite core evidence |
| CERI | Catalyst and Estimate-Revision Intelligence |
| Combined decision | The run-level synthesis of fundamental and technical scores into a research label |
| Config hash | Stable hash of effective configuration used to reproduce a calculation |
| Evidence provenance | Source, cutoff, version, and hash metadata that explains where a value came from |
| Immutable evidence | Persisted source or decision-time record that is retained for audit/reproduction |
| Local admin | Unsafe route class restricted to local hosts and, where configured, CSRF-protected |
| No-order boundary | SwingLens must not place, modify, or cancel broker orders |
| OWPE | Outcome-Calibrated Winner Probability Engine |
| Point-in-time | Uses only evidence available at the decision cutoff |
| Rebuildable artifact | Cache, export, or operational byproduct that can be regenerated from retained evidence |
| Retention | Policy for preserving, archiving, redacting, purging, or cleaning data/artifacts |
| XLSX deferred | Spreadsheet exports are not promised until implemented and tested separately |
